# Лекція 5 — Захист даних і криптографія в AWS

**Курс:** Інформаційна безпека телекомунікаційних та хмарних технологій  
**Модуль:** 1 — Основи безпеки телекомунікацій та AWS  
**Кількість слайдів:** 35

---

## Опис лекції

Лекція охоплює комплексний підхід до захисту даних у хмарному середовищі AWS: від фундаментальних принципів криптографії до конкретних AWS-сервісів та регуляторних вимог. Розглядаються практичні патерни шифрування для телекомунікаційних систем.

---

## Цілі навчання

Після завершення лекції студент повинен вміти:

1. Пояснити три стани даних (at rest, in transit, in use) та механізми їх захисту
2. Розрізняти симетричну та асиметричну криптографію, знати їх застосування
3. Описати принцип конвертного шифрування (Envelope Encryption) та пояснити, чому він використовується в AWS
4. Налаштовувати AWS KMS: створювати CMK, визначати Key Policy, вмикати ротацію
5. Обрати та налаштувати відповідний тип шифрування для S3, EBS, RDS, DynamoDB
6. Налаштовувати TLS/mTLS та управляти сертифікатами через ACM
7. Безпечно зберігати секрети в AWS Secrets Manager та Parameter Store
8. Розрізняти AWS KMS та CloudHSM та обирати відповідне рішення
9. Використовувати Macie, Config та Security Hub для виявлення проблем із шифруванням
10. Пояснити загрози Post-Quantum Computing та поточний стан PQC стандартів
11. Проектувати архітектуру Defence in Depth для захисту чутливих даних
12. Автоматизувати налаштування шифрування через Terraform (IaC)
