## CVE та інциденти, що розглядаються на лекції

| CVE / Інцидент | Рік | Опис |
|----------------|-----|-------|
| **Capital One Breach** | 2019 | SSRF → AWS IMDSv1 → витік IAM credentials ($80M штраф) |
| **SS7 Bundestag Hack** | 2014 | Прослуховування депутатів через SS7 SMS interception |
| **Bitcoin 2FA Bypass** | 2017 | SS7 перехоплення SMS → крадіжка BTC з Coinbase |
| **CVE-2021-44228** (Log4Shell) | 2021 | RCE через JNDI in Apache Log4j (A06 Vulnerable Components) |
| **Twitter Bitcoin Scam** | 2020 | Соціальна інженерія → злом адмін-акаунтів (A07 Auth Failure) |
| **Optus Data Breach** | 2022 | Unauthenticated API endpoint → 9.8M записів (API1 BOLA) |
| **T-Mobile SS7** | 2017 | Демонстрація SS7 location tracking на US операторі |
