# Лекція 7 — Безпека веб- та телеком-застосунків

**Курс:** Інформаційна безпека телекомунікаційних та хмарних технологій  
**Модуль:** 2 — Захист сервісів, інциденти та відповідність  
**Кількість слайдів:** 38  

---

## Опис лекції

Лекція охоплює два ключові домени застосункової безпеки: веб-застосунки та телекомунікаційні системи. Розглядаються методи атак, вразливості протоколів SS7/Diameter/GTP/SIP, сучасні стандарти захисту 5G, а також хмарні рішення AWS для захисту веб та телеком середовищ.

---

## Цілі навчання

Після завершення лекції студент повинен вміти:

1. Пояснити OWASP Top 10 (2021) та вказати методи захисту для кожної категорії
2. Описати механізм SQL ін'єкцій та застосовувати параметризовані запити
3. Розрізняти XSS, CSRF та SSRF атаки та впроваджувати відповідний захист
4. Пояснити архітектуру SS7 та категорії атак (відстеження, перехоплення, DoS)
5. Описати вразливості Diameter та GTP і захист через Edge Agent / GTP Firewall
6. Аналізувати атаки на SIP (VoIP) та обґрунтовувати необхідність SBC та SRTP
7. Порівняти безпеку 4G та 5G (SUCI, SEPP, SBA, Network Slicing)
8. Ідентифікувати типи телеком-шахрайства та механізми FMS виявлення
9. Налаштовувати AWS API Gateway з Cognito, Lambda Authorizer та WAF
10. Впроваджувати DevSecOps pipeline для веб та телеком-застосунків
11. Зіставляти вимоги NIS2, PCI DSS v4.0, OWASP ASVS, GSMA FS.11
