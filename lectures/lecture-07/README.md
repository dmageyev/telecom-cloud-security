# Лекція 7 — Безпека веб- та телеком-застосунків

**Курс:** Інформаційна безпека телекомунікаційних та хмарних технологій  
**Модуль:** 2 — Захист сервісів, інциденти та відповідність  
**Аудиторія:** Студенти напряму «Кібербезпека»  
**Тривалість:** 2 академічні години (90 хв)  
**Кількість слайдів:** 38

---

## Мета лекції

Сформувати у студентів комплексне розуміння загроз і механізмів захисту веб- та телекомунікаційних застосунків: від класичних OWASP-вразливостей до специфічних протоколів мобільних мереж (SS7, Diameter, SIP, GTP, 5G) та хмарних інструментів захисту.

---

## Цілі навчання

Після завершення лекції студент зможе:

1. Пояснити OWASP Top 10 та API Top 10, навести приклади для кожної категорії
2. Описати механізми SQL Injection, XSS, CSRF, SSRF та IDOR і методи їх нейтралізації
3. Налаштувати базовий захист веб-застосунку: WAF, TLS 1.3, OAuth 2.0/PKCE
4. Пояснити вразливості SS7 та Diameter і методи їх виявлення
5. Описати архітектуру безпеки VoIP/SIP (SIPS, SRTP, SBC)
6. Аналізувати загрози SMS (SIM Swap, SS7 interception) та альтернативи 2FA
7. Пояснити ризики GTP та принципи захисту мобільного ядра мережі
8. Порівняти механізми безпеки 4G та 5G (AKA, SUCI, SBA)
9. Налаштувати AWS WAF, Shield та API Gateway для захисту телеком-бекенду
10. Організувати DevSecOps pipeline із SAST, SCA та DAST для веб/телеком-застосунків
